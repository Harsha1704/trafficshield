## 2. Itemized Required Corrections

### Correction 1: Relabel Disputed "CICIDS2017 Stream" Evaluation
- **Target Files:**
  - `reports/m10_cross_dataset/cross_dataset_results.md`
  - `reports/m10_cross_dataset/verified_model_metrics.csv`
  - `reports/m10_cross_dataset/m10_summary.md`
- **Issue:** The dataset label `"CICIDS2017 Stream"` implied that real streaming network traffic from the CICIDS2017 benchmark was captured or evaluated.
- **Correction:** Relabel dataset to **`"Synthetic_CICIDS2017_Fixture"`** (or `"Synthetic CICIDS2017 Fixture (Offline Adapter Validation)"`).
- **Annotation:** Add an explicit notice: *"Evaluation conducted using the 10,000-flow synthetic fixture generated by `CICIDS2017Adapter.generate_synthetic_cicids_dataframe()`. This verifies pipeline ingestion and rate calculations offline, but does NOT represent empirical generalization on authentic CICIDS2017 network traffic."*

### Correction 2: Reconcile "79+ Column Policy" Claims
- **Target Files:**
  - `reports/m10_cross_dataset/m10_summary.md`
  - `ingestion/adapters/cicids2017_policy.py` (module docstring)
- **Issue:** Documentation claimed "all 79+ CICIDS2017 columns codified into explicit specifications".
- **Correction:** Amend to: *"Codified 58 explicit specifications covering all primary forward, reverse, bidirectional, and label columns, backed by an automated keyword fail-safe that rejects any unmapped column containing reverse or label indicators."*

### Correction 3: Reconcile "120+ Features" Claim in Feature Compatibility Audit
- **Target File:**
  - `reports/m10_cross_dataset/feature_compatibility_audit.md` (Section 3, Line 55)
- **Issue:** Stated: *"The complete mapping of all 120+ features across both datasets is exported to feature_compatibility_matrix.csv"*.
- **Correction:** Amend to: *"The complete mapping of all 107 audited features across both datasets (49 UNSW-NB15 specifications + 58 CICIDS2017 specifications) is exported to feature_compatibility_matrix.csv."*

### Correction 4: Reconcile Executive Summary Statement on Synthetic Data
- **Target File:**
  - `reports/m10_cross_dataset/m10_summary.md` (Section 1, Point 1)
- **Issue:** Stated: *"Refused to fabricate synthetic metrics for absent real data"*, while reporting Track B zero-shot metrics on a synthetic fixture without clear labeling.
- **Correction:** Clarify that Track A native training on real data was properly marked `NOT RUN (Dataset absent locally)`, while Track B zero-shot transfer was performed on an offline synthetic test fixture to test pipeline compatibility, and must be interpreted as such.
